# Portfolio SPA (React + Vite)

Portfólio em formato SPA feito com **React + Vite + TypeScript**, com rotas para **Projetos**, **Demos** e **Engineering Notes**.  
Deploy pensado para **Vercel** e versionamento via **GitHub**.

## Stack
- React + TypeScript
- Vite
- React Router
- (Opcional) React Markdown (para a página de Engineering Notes)

## Rodar localmente
```bash
npm install
npm run dev
````

## Build

```bash
npm run build
npm run preview
```

## Deploy (Vercel)

* Importar o repositório no Vercel e fazer deploy.
* O projeto inclui `vercel.json` com rewrite para evitar 404 em rotas do React Router.

```

Se quiser, eu também posso te mandar um `README` versão “currículo”, com 3 bullets de impacto e um mini roadmap (bem curto) — fica mais profissional sem virar textão.
```
